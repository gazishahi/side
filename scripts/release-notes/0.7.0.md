## New

- **Side hears from every Claude Code session.** Turn on Claude Code's hooks (Side offers them once in the session switcher; Settings › Agents › Claude Code sessions turns them on or off, for every project or one) and Side knows what each session is doing and what it's waiting for, including sessions in other terminals. Only Side's own entries are added to Claude Code's settings, with a backup of the file kept beside it. The hooks are what the review queue and line authorship below are built on.
- **Changes is a review queue.** While a project has uncommitted changes, Changes lists each Claude Code session that made some, by what it was asked, with its state, size and files; then your own edits; then whatever no session explains; then the whole branch. Choose one to see only its changes. Without the hooks, changes show as not attributed.
- **Approve, commit, discard.** Approve a session's changes a hunk at a time, or all at once; approvals last across relaunches and hold while other edits move them. Commit Approved… commits exactly what you approved, with a message drafted from what the session was asked. Discard… takes a session's changes out of your files, after asking, and refuses when someone else's lines are built on them.
- **Ask for Changes.** Write a comment on a session's changes and Side sends it to that session in its terminal tab, or copies it to paste when the session is in a terminal outside Side.
- **Who wrote each line.** With the hooks on, the Editor's change bar says who changed a hunk and what they were asked ("Changed by Claude Code · Fix the flaky login test"). Your saves in Side are You.
- In the activity list, a finished Claude Code session whose changes Side attributed has Review, which opens them in Changes; anything that has ended has Dismiss.
- Tabs share their strip equally, so titles that change as you work (Claude Code retitles its tab every few seconds) no longer move the tabs about.
- Translucent background is one sheet of the system's glass; the terminal and the editor draw on it. Working is a short turning arc.

## Changed

- The terminal beside the Editor (Show Terminal Beside, ⌥⌘T, and Follow) is gone. Tearing a terminal out into a window of its own stays.

## Fixes

- Backspace at a prompt erases a whole character like é or 日, not one byte of it.
- A terminal restored after a restart comes back below its old screen, instead of writing over it.
- Terminals that print a lot of output keep up with it faster.
- The new-tab + sits evenly in the window's corner.
- The activity list's states line up, and long titles are cut short instead of pushing them off the edge.
- Changes no longer draws a new file's line numbers a few rows below their lines.

## Experimental

- A new terminal engine, off by default: Ghostty's terminal emulator (libghostty-vt) drawn by Side's own renderer, with ligatures, box drawing drawn to the cell, every underline style, right-to-left text, and Find (⌘F) over the terminal's scrollback. To try it: `defaults write com.shahi.side terminal.engine alloy`, then restart Side. `defaults delete com.shahi.side terminal.engine` goes back.
