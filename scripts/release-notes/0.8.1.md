## Changes

- **Tab titles fade out at the edge.** A name too long for its tab now runs on and fades out before the ×, instead of ending in "…".
- **A torn-out tab shows its whole name.** Dragged out of the strip, the card shows as much of the name as it has room for, not the tab's shorter cut.
- **Lines between tabs.** A faint line now separates tabs side by side, and disappears next to the selected or hovered tab.
- **Translucent background in light mode lets more of the desktop through.** Before, it read as plain grey.
- In the activity pill, project logos with a see-through background sit on a rounded tile, so stacked logos stay distinct.

## Fixes

- Switching the appearance from Dark back to Match System could leave the editor or the window's background dark. Everything now follows the change.
- With the editor set to translucent, CSV files no longer draw solid rows.
- In the activity list, a long description no longer runs under the × when you hover a row.
