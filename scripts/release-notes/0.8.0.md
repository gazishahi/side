## New

- **A new terminal engine, on for every terminal.** Ghostty's terminal emulator (libghostty-vt), drawn by Side's own renderer. It answers keys faster and keeps up with heavy output. It brings ligatures, box drawing drawn to the cell, every underline style, right-to-left text, and Find (⌘F) over the terminal's scrollback. If something looks wrong, `defaults write com.shahi.side terminal.engine swiftterm` and a restart go back to the old engine for now; please tell us what you saw.
- **Images in the terminal.** Programs that show pictures with the kitty graphics protocol (`kitten icat`, image previews in file managers, plotting tools) draw them in the terminal: PNG and raw images, animations, and images placed in the text by Unicode placeholders.
- **Font weight.** Settings › Appearance › Fonts has a Weight for the editor's and the terminal's font: any weight along a variable font like SF Mono, or one of a family's own weights (Fira Code's Light to Bold). Bold text stays a step heavier.
- **Side in the menu bar while it's closed.** When you quit Side with terminals still running, a menu bar icon lists them by state (Needs You, Working, Finished, Failed), with each one's project, what it was asked or its command, and how long it's been. Choose one to open its tab; hold Option to stop it; Stop All asks first. It goes away when Side opens. Settings › General › Terminal turns it off.
- The terminal tells programs when it gains and loses focus, for the editors and tools that ask (focus reporting).
