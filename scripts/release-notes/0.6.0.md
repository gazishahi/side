## New

- **A welcome.** A new install opens on a short tour of Side: the five stages, each played in a miniature Side; how branches, terminals and chats work; your accent, keymap and editor theme, live; the agents Side found on your Mac, or how to install one; and a project to open, including folders you've had open lately in VS Code, Zed or Cursor. Help › Welcome to Side shows it again.
- **Every session, in one place.** ⌃⌘S opens the session switcher: every terminal program and agent across your projects, the ones that need you first, then what's working. Type to find one by title, agent or branch. Claude Code sessions running outside Side are listed too. The activity pill says what a program is waiting for in its own words ("Needs permission: Run swift test?") when the program reports it.
- **Terminal's tabs are the project's.** Switching branches no longer swaps your tabs. A tab working on another branch says which, even when an agent moved itself into a worktree. A new tab opens in the branch you're on, and there's a + after the tabs for one.
- **Every branch is a track.** Branches lists every local branch, with nothing to adopt; a branch made or checked out in a terminal shows within a second. Under each branch, the board shows what's running on it. Picking a branch checks it out in the main folder when that's safe, and opens it in a folder of its own when it isn't, saying why.
- **Pull requests on Branches.** A branch's row shows its pull request (open, draft or merged), and an open PR's base becomes the branch's base. It works with `gh`, `glab`, or no tool at all for a public repository on GitHub or GitLab.
- **Make it yours.** Settings › Appearance has an accent color, Interface follows the theme (Side's surfaces take the editor theme's background), Translucent background (the desktop through the window, blurred), and Surfaces: Liquid Glass or Solid.
- **Terminal and Agent share Claude Code chats.** Agent lists the folder's Claude Code chats, including ones from Terminal, and opens them with their history. Continue in Terminal resumes a chat in a new tab, and a Claude Code tab has Open in Agent.
- **Agent's messages draw more.** Mermaid diagrams, sortable tables, SVGs and pictures from the project. A jump bar beside the conversation has a tick per message you sent; click one, or press ⌥⌘↑ and ⌥⌘↓, to go there.
- **A terminal beside the Editor.** Show Terminal Beside (⌥⌘T), or Show Beside Editor on a tab, docks a session at the window's edge. With Follow on, a file the program changes opens in the Editor at the changed line.
- **Open With Side.** Files and folders open in Side from Finder's Open With and the Dock. A file outside your projects opens in a window of its own, and Open Folder as Project turns that window into a project.
- **PDFs** open in the Editor, with search, zoom, selectable text and working links.
- Right-click Side in the Dock for your open projects, what each is doing, and Recent Projects.
- The activity pill leads with the logos of the projects its news is in.
- The Markdown preview shows README pictures and badges.
- The ⌃⇥ strip fits however many projects are open, and the pointer picks a project while ⌃ is held.

## Fixes

- Privacy permissions you grant to a terminal (Screen Recording, say) now last across restarts and updates. Terminal sessions run under one helper, Side Session Keeper, that macOS remembers.
- A window with no project opens Terminal in your home folder instead of asking for a project.
- Switching branches with Terminal in front no longer leaves it blank.
- A selected tab's title no longer loses letters to its bolder weight.
- A stacked branch counts how far ahead and behind it is against its own base, not the default branch.
- A white project logo keeps its edge on light backgrounds.
