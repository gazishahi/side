## Fixes

- **Open files come back.** Returning to a project sometimes showed no files in the Editor: switching branches wrote an empty list over the files that were open, and a branch with no list of its own opened none. A project now reopens the files you had open, and a branch you haven't used yet opens the project's last ones.
- With the editor translucent, Markdown previews show the window's glass instead of a solid background.
- A Markdown tab dragged out of the strip no longer shows its preview on a green background.
- A working tab's shimmer no longer shows the title twice after you select the tab.
- The activity pill's contents sit in its middle, with even space on both sides.
