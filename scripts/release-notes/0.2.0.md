## Make

- **Live Markdown.** View → Live Markdown sets a Markdown file as you'd read it: the reading font, headings at their sizes, bold and italic, math typeset, pictures, rules and tables with their columns lined up. The Markdown shows again on the line you're editing. Format → Bold, Italic and Link (⌘B, ⌘I, ⌘K) in Markdown files.
- **Writer Mode** (View → Writer Mode, ⌃⌘W): the text alone, in one column. Word count, typewriter scrolling and dimming of other paragraphs, each a toggle in Settings.
- **Spreadsheets.** CSV, TSV and Excel workbooks open as a spreadsheet: column letters, cells you can select, sort and copy, the selection's sum and average, Find, and a workbook's own number formats, fonts and colors. A sheet follows its file as it changes.
- **LaTeX.** Highlighting, texlab, and Build (⌘B): latexmk runs, the PDF opens beside the window and refreshes on every save, errors go to Problems, and SyncTeX goes both ways (Show in PDF, and ⌘-click in the PDF). Needs a TeX installation such as MacTeX.
- **Svelte**, with its language server, and embedded languages colored as themselves: HTML's script and style, Svelte's, and Markdown's code blocks.
- **Math in the Markdown preview**, and front matter shown as a card.
- **File-type icons** in the explorer, Quick Open and search.
- **Tabs.** Two files with the same name say which folder each is in. A tab dragged out of the window becomes a small window of itself, and goes back to its place when let go inside.
