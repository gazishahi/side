## New

- **The project switcher, redesigned.** ⌃⌘P or the project chip brings it out of the stage bar on glass, just above the bar, as the palette comes. Projects are a list (a grid in Settings › General). The selection slides from one to the next, ⋯ and × fade in on hover without moving anything, and Open… ⌘O opens a project from any stage.
- **⌃⇥, quieter.** It cycles through the projects that are open. A quick ⌃⇥ just switches, with no panel; hold ⌃ and the strip comes out of the bar, its line about the project in full under the tiles.
- **Settings in columns.** Each pane's sections flow into one to three columns with the window's width. Appearance shows a live preview of the editor, the terminal and the interface beside its choices. Shortcuts are grouped by area, each one folding open, and you can find a shortcut by pressing its keys or show only the ones you've changed or that conflict.
- **The update pill.** A spinner while it checks, a checkmark when Side is up to date that closes up and goes, a blue Update to x, a green Restart to update, and Update failed — Retry. Hover for an × that puts it away.
- **One Claude Code conversation in two tabs.** When two terminals are on the same conversation, the tab says so, with Go There, or End That One when no tab shows the other.
- **Disk space.** The bar tells you when your disk is low, and again when it's nearly full. Click to open Storage in System Settings.
- The file explorer is now part of the window, on the same glass as the palette: the palette, Find and the switcher put it away, and it never takes the keyboard from the window.
- The last tab left in a strip has an × after its name on hover.
- Project icons come from more places: an .icns in the repository, an Expo app's icon, and a package's in a monorepo. Choose Icon… picks one by hand.

## Fixes

- After a restart, recovered Claude Code tabs no longer fill with numbers that never stop. The new shell no longer inherits the old program's mouse reporting.
- A terminal whose connection drops while its session still runs reconnects, instead of saying the session ended. Closing a tab whose terminal another Side took ends that terminal.
- A tab dragged out of the strip no longer stays frozen on screen.
- The file explorer no longer opens by itself when you switch projects.
- The activity pill no longer says Claude Code finished for a session that's only sitting idle, and no longer comes and goes with Settings in front.
- A tab's title takes clicks again.
- The working shimmer carries on after you switch stages and back.
- Closing down to one long-titled tab no longer shows its name twice.
