## New

- **Stages say what they are.** Make, Think, Review, Run and Tracks are now Editor, Agent, Changes, Terminal and Branches. Each has an icon of its own in the stage bar, an outline at rest and solid when selected, and only the selected stage shows its name. Pinned stages and the stage a window was on carry over.
- **Projects in one window.** A window can hold several projects and switch between them in place, each with its own tabs. The projects you leave stay open in the background. The project chip at the bar's leading edge shows the repository's own logo when it has one, and a dot when another project needs you.
- **The project switcher.** Press ⌃⌘P or click the project chip to see your projects as cards in the middle of the window, in a grid or a list. Each card shows where the project is, what's happening in it and its terminals. Open projects come first and recent ones follow, dimmed. Type to narrow the list and press Return to switch, or ⌘Return to open the project in a new window. ⌘⌫ puts a project away, and anything past nine is under More projects. Hold ⌃ and press ⇥ to cycle through them; letting go switches. ⌃1–9 still go straight to one.
- **The activity pill.** When something happens out of sight, in any project or stage, it shows beside search: an agent working or finished in a tab you aren't on, a terminal's bell, an Agent turn or an update downloading. Click it to go there.
- **Claude Code is the default agent.** New tracks start on Claude Code, or on whichever agent you choose in Settings › Agents › Default agent. Every agent can now read the Editor's errors and warnings, a paused program in the debugger and the track's ports.
- **Heron is retired.** Side's own agent, its modes and Settings › Providers are gone. Past Heron conversations still open to read, with Continue on your default agent where Send was. First run now helps you set up an agent.
- Terminal tabs show what's running in them: Claude's mark for Claude Code, OpenAI's for Codex, and symbols for editors, git tools and the rest. A working tab shimmers, and every working tab shimmers in step.
- Claude Code and other terminal programs switch with Side between light and dark, including in a window on another Space.

## Fixes

- Updating Side no longer offers to report a crash on the next launch.
- Terminals no longer freeze when the Mac runs out of disk space. If a terminal's session ever does end unexpectedly, its tab says so.
- Changes no longer shows the previous project's files.
- Terminals reopened after a relaunch come back at their real size, with the cursor where it was.
- Holding ⌘W or ⌘T closes or opens one tab, not a stream of them.
- Closing several tabs quickly no longer closes the wrong one or leaves the strip unresponsive.
- Leaving Editor while an agent worked no longer stretches the window past the screen.
- ⌘1–9 reach Terminal's tabs.
- Clicking a notification for a project this window had switched away from switches back, rather than opening a second window.
- A tab dragged out and dropped back keeps its icon and fades into place.
