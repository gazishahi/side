## New

- **Tabs, redone.** Make and Run share one tab strip. Drag a tab out of the window and it becomes a card that grows into a new window where you drop it. Run tabs can be renamed with a double-click.
- **Run tabs name what's running.** Claude Code, Codex, OpenCode, vim or anything else that sets a terminal title names its tab until it finishes. A name you give the tab still wins.
- **Sounds and notifications when an agent needs you.** When Side is in the background, or you're on another track or stage, Side plays a sound and shows a notification when an agent needs you or a run fails. Turning on "Also when a turn finishes" adds finished turns. Clicking a notification takes you to that track. Set them up in Settings › Notifications.
- **Zoom.** ⌘= and ⌘− grow and shrink the editor in Make or the terminal in Run, and ⌘0 goes back to the default. A small pill shows the size while you zoom. In Writer mode, the zoom shows beside the word count.
- **Updates in the bar.** When a new version is out, a pill beside search offers it, with the release notes, and shows the download's progress. Nothing downloads until you click.
- **Motion.** Panels, the palette, tabs and stage switches move on springs. Reduce Motion turns them into crossfades.
- **One set of status words and dots** across Think, Tracks, Run and tabs: Needs you, Working, Failed, Ready for review.
- The base branch is the first row in Tracks, so you can work on it without a track.
- Dotfiles (.env, .github) and files like Dockerfile and Makefile show in the explorer, Quick Open and the agent's file tools.
- The Markdown preview shows local pictures. Remote pictures load when you click them.
- Dropping a file or picture into a Run terminal types its path, so Claude Code can take image drops.

## Fixes

- Moving the window by its top row no longer scrolls the open file to its top.
- In the Markdown preview, a long table cell wraps inside its column instead of running into the next one.
- Editor themes now color Review's diff, Make's background, the top row and the line numbers.
- Switching Run tabs no longer shows a blank terminal for a moment.
- Toggle File Explorer works wherever focus is.
- A new tab's title shows right away.
