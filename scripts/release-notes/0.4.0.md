## New

- **Terminals keep running when Side quits.** Each Run terminal now lives in a small process of its own, so quitting Side, an update or a crash no longer ends what's running. When Side opens again, the tabs come back with their scrollback, attached to the same shells. Turn it off in Settings › General › Run.
- **Agents pick up where they left off.** After a restart of the Mac, a Claude Code tab resumes its conversation by itself. Codex and OpenCode resume their latest one, and lazygit and tig start again. Anything else offers Run Again.
- **Notifications while Side is closed.** When Claude Code, Codex or another agent finishes a turn in a terminal nobody is watching, or a program rings the bell or sends a notification, you hear about it. Clicking the notification opens Side on that tab, switching to its track if needed.
- **Running Terminals** (Window menu): every terminal still running, across projects, with what it's running, how long it's been quiet and its memory, and End for each.
- Closing a tab with something still running in it asks first. Turn that off with "Don't ask again" or in Settings.
- **Live command cards in Think.** A command Claude Code or Codex runs shows as a card with its output as it arrives, how long it has run, and how it ended.
- A new app icon.

## Fixes

- Run no longer slows down in a project folder that isn't a Git repository.
- Closing a Run tab switches to the next one at once.
